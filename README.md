# 个人工作台 · 晨雾奶油 Cream Reverie

> 早上规划、白天专注、晚上复盘的温柔工作台。**本地优先，双击即开，数据 100% 存本机。**

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## ✨ 快速开始

**无需安装任何东西**：

- Windows：双击 **`启动工作台.bat`**（或直接双击 `index.html`）
- macOS / Linux：直接用浏览器打开 `index.html`

全部功能离线可用；联网时自动增强（天气 / 每日一句 / 汇率 / 热点 / 治愈萌宠，断网优雅降级，绝不报错）。

## 🍦 是什么

一个单页效率与生活工作台（纯 HTML/CSS/JS，零框架、零构建依赖）：

- **今日总览**：天气+空气质量、农历节气月相、今日三大件、可折叠的 15 张卡片（常驻三大件/待办/日志，其余一键展开，含锦鲤引言水墨翻卡）、**小雾团**（可以给它起名字，它会记得你们一起过的日子）、**旧忆卡**（同一天，看到几年前今天写下的字）、窗外窗景页、收工仪式
- **计划**：待办（清单/子任务/重复/时刻提醒/四象限/搜索/多选批量）、月历+时间轴、月度目标、倒数日（农历生日）、年度愿望
- **记录**：习惯打卡（打勾/次数型）、每日日志（Markdown+今日一问 365 题）、心情、随手笔记（语音速记）、简单记账（预算）、书影剧馆（可开启 3D 书架）、健康小屋、技能空间（B站内嵌）
- **工具**：番茄钟（专注液态珍珠/休息暖金星球双视觉 + 小花园 + 六源声音面板：雨声/篝火/白噪/雨夜钢琴/晨间氛围/Lo-Fi 全部 CC0 真实录音无缝循环（失败回落合成）+ 本地音乐）、⌘K 万能面板、常用链接二维码、轻娱乐角（吃什么转盘带食谱/涂鸦板/治愈萌宠）
- **回顾**：ECharts 统计看板、周报、成就徽章、4000 周人生刻度图
- **视觉**：动态壁纸（晨露/夜雾星座，ThreeUI 着色器移植）、三扇窗景页（山雾四季/和塔暮色/书房灯下）、晨雾奶油 / 夜雾 / 暮霞粉三主题、三套点缀色 + 自定义、霞鹜文楷内置字体
- **氛围**：跟随节律——沉浸场景 / 音景 / 主题按时段（晨・昼・暮・夜）自动编排，四段每一格都能自己改；默认关闭，不点它就不会动你的界面
- **纸**：日（一页纸）· 周 · 月（月历海报，可以贴墙）· 季 · **年（年刊册子：封面 + 一月一页）**，一键打印或存成 PDF；不装任何 PDF 库，数据全在本机
- **打断记录**：专注中被什么打断，点一下记一笔（六种来源）；统计页看分布与时段，一页纸上也留一行 —— 只看清，不考核
- **桌面版**：系统托盘常驻 · Ctrl+K 全局唤出 · 出门前点 × 收进托盘（不退出）——**关掉窗口也会按点提醒**：待办到点、倒数日与生日、晨间、收工
- **动效**：统一的缓动/时长/模糊/层级四族设计令牌（`css/main.css` 的 `:root`），主题切换时渐变层与壁纸交叉淡入不硬跳、弹窗/命令面板/抽屉都有退场动画、卡片与列表错峰入场、拖拽重排带位移动画、下拉刷新跟手回弹；跟随系统「减弱动态效果」，设置里也有一键静音动效
- **快捷键**：`Ctrl+K` 万能命令面板（捕捉/跳转/翻译/搜索）、`N` 新笔记、`T` 新任务、`空格` 声音播放/暂停、`D` 切换深浅色、`Esc` 关闭弹窗/面板（输入框内自动失效，设置页可查全表）

## 📦 三种形态

| 形态 | 用法 |
|---|---|
| 本地文件夹版（推荐日常） | 双击 `启动工作台.bat` |
| 单文件版 | `node build.js` 生成 `个人工作台.html`（约 1.5MB，含全部字体/图标/代码；窗景页与 3D 书架为文件夹版专属） |
| 云端版（多端同步 + PWA + AI） | `ENV_ID=你的环境ID bash deploy.sh` 部署到腾讯云开发 CloudBase，详见 [开发交接文档 §6](开发交接文档.md) |

## 🔐 数据与隐私

- 全部数据存浏览器 localStorage + IndexedDB，**不上传任何服务器**
- **每日自动快照**：每天首次打开自动把全量数据快照存本机 IndexedDB（保留 7 份），设置 → 数据管理可随时一键恢复
- 随时导出：JSON 全量备份 / 日志笔记 Markdown / 账单 CSV（设置页；超过 7 天没导出会温柔提醒）
- 云端版需自行部署：访问密码服务端校验，密钥（BYOK）只存本机
- 开发者回归：`node tools/test-smoke.mjs` 一键冒烟全部路由（见开发交接文档 §9）
