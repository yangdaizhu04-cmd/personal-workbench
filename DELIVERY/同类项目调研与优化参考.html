01

先说结论

核心判断

你的项目与三类竞品对照后，单模块功能清单上没有明显缺口——待办四象限、习惯打卡、番茄钟、统计看板、徽章、周报，竞品有的你基本都有。真正的差距集中在三点：旧数据会不会主动"浮出"（回顾机制）、激励有没有代价与流通（激励经济学）、录入摩擦能不能再压一半（输入层）。这三点恰好都是纯前端可实现、不破坏单文件架构的。

按重要度排，本次调研带来的五个可执行方向：

方向一句话来源原型
1 · 年度报告页把统计看板数据做成翻页式"我的 2026"，纯前端动画 + 可导出长图，是天然的分享与仪式感功能Spotify Wrapped
2 · 递归复盘链周报已有，向上扩月报/季报，且月报自动汇总四周周报，而非重新生成LifeOS for Obsidian
3 · 心情晴雨表心情数据已有，补温度曲线 + 情绪占比 + 月历色阶三种回顾视图，并接进周报Moo 日记
4 · 专注金币经济番茄攒金币兑换主题/白噪/装扮，放弃留"枯萎记录"——徽章是收集，经济才是激励Forest
5 · 一句话录入层「明天下午3点开会」自动填日期提醒，「午饭32」自动记金额分类——待办与记账共用一套解析滴答 / 一木

口径说明：调研中 subagent 曾建议"新建周报 / 数据导出 / 番茄绑定待办"等，复核阶段已对照需求方案 v15 逐项确认——这些你都已实现（周报、JSON 全量备份、番茄绑定待办或技能卡、任务拖时间轴、枯苗记录、每日旧忆回顾卡），相关建议已全部改写为"升级"口径，不重复列入。

02

海外开源同类

海外项目分三族：面板聚合类（Homepage / Dashy / Homarr）做"服务入口 + 信息卡片"，与你的今日总览对位；本地优先 Notion 替代（AFFiNE / AppFlowy）验证了"同数据多视图"方向；效率生态（Super Productivity、Obsidian 仪表盘插件）与你的待办/番茄/日志直接重叠。

项目独特之处对你最值钱的点对位
Homepage~32.4k ★ 全静态、快；Quick Launch 首页即搜；服务健康信息卡 链接活性检测——你的链接卡片可显示"在线/失效"状态点 部分重叠
Dashy★ 未确认 可视化 UI 编辑器；多用户各自定制主题与布局 多设备配置隔离——云同步时"数据同源、皮肤各裁" 部分重叠
Homarr★ 未确认 拖拽式配置（No YAML）；自定义卡片 = 填一个 HTTP API 即可渲染任意数据源 自定义 API 卡片——用户自己配 endpoint 接天气/汇率/自建服务，零代码扩卡 部分重叠
AFFiNE60k+ ★（2025-12 官方口径） 文档 + 无限白板 + 关系数据库三形态共享同一数据源 同源多视图——一份任务数据在月历 / 看板 / 清单间切换 部分重叠
AppFlowy~66.5k ★（2025-11 第三方口径） Rust + Flutter 本地优先工作区，数据库/看板/日历一体，跨端统一 "数据完全归用户所有"的产品叙事与你的定位互证 部分重叠
Super Productivity★ 未确认 任务 → 时间盒 → 自动耗时记录 → 统计的完整闭环，完全离线无账号 专注闭环——你已有番茄绑定待办，可借鉴的是其统计口径：按任务累计"实际耗时 vs 预估" 高度重叠
Obsidian Homepage 插件★ 未确认（2026-08 新） 仪表盘不存数据，只自动发现 Markdown 里的任务/日志/项目并聚合到首页 "写日志即喂仪表盘"——你日志里的 [ ] 勾选框、#标签可自动浮出到总览 高度重叠

星数为 2026-09-14 快照；标注"未确认"的四个项目本次未搜到权威星数，故不参与星数量级对比。AppFlowy 部分旧文沿用了其首年（约 2022）的 30k 数据，已弃用。

03

中文同类产品

中文侧的启示更直接：这些产品的招牌设计，恰好都落在你项目的既有模块上，属于"同一块地，别人种出了别的庄稼"。

产品独特设计对位与可借鉴
滴答清单 所有模块挂在"任务"这个中心对象上（番茄挂任务计时、打卡进四象限）；快速添加时自然语言解析日期时间 联动你已部分实现；缺的是输入层的自然语言解析
flomo 浮墨 被动回顾（每日回顾自动抽旧卡片）+ 主动回顾（输入前先看同标签旧笔记）；标签树 + 反向链接 你的旧数据只进统计图表，缺"重新露脸"通道——但每日旧忆卡已有，可扩为标签树 + 日志反链
Forest 专注森林 专注做成有代价的游戏：中途弃用树枯死、永久留在时间轴；专注攒金币换树种（据 2018 年资料：500 起、每次递增 100、1000 封顶，现行或有调整）；虚拟种树兑现公益真树 你已有枯苗 + 小花园；缺的是金币经济——徽章是"收集"，Forest 是"赚-花"闭环
潮汐 番茄钟重新包装成"身心健康仪式"，白噪与计时深度绑定成场景预设 你的六源白噪可组合保存为"深夜图书馆""雨天咖啡馆"一键场景
钱迹 以"账户"而非"流水"为中心——记账自动增减账户余额，构成资产全景（600 万用户，"三无"定位） 你的记账偏流水；可加账户余额层，月报看"钱在哪"而不只"花了多少"
一木记账 语音/一句话记账："午饭 32"自动解析金额+分类+账户+时间；WebDAV 自主备份 你有语音笔记模块——复用它加正则解析即得语音记账，与待办的自然语言解析共用一套
格志 / Moo 日记 格志：结构化提问按"日问→月总结→年回顾"节奏编排；Moo：心情晴雨表（温度曲线 + 情绪占比） 你的 365 题可升级为按目标编排 + 月末自动汇出"问答合辑"；心情补晴雨表视图
memos
开源 · flomo 理念		 自托管快记，Markdown 原生时间线（~63k ★，2026-09 GitHub API） 时间线视图与标签体系可参考进日志/语音笔记
LifeOS for Obsidian
模板 1.1k ★ · 插件 582 ★		 递归复盘链：周记复盘本周日记、月记复盘每周复盘、季记复盘每月复盘（2024 Obsidian 年度最佳模板奖第三名） 你最值得抄的结构——周报已有，向上扩月报/季报，上级自动以下级为素材
04

2025–2026 玩法趋势

五个趋势按"对本项目的可落地度"排序——前两个是低垂果实，第四个要诚实标注能力边界。

T·1

年度报告式数据回顾Spotify Wrapped 2025：首日 2 亿+ 用户，比上一年 +19% TechCrunch

翻页式视觉报告 + 社交分享已成年度仪式；中文平台年度账单同理（支付宝/网易云，长期现象级）。对你：纯前端可实现，且"本地数据也能有 Wrapped"是反向差异化卖点。Spotify 已把该玩法扩展到全历史回顾（2026-05），区间可支持年度/季度/自定义。

T·2

AI 复盘 / 周报助手Reflection 自动生成周/月/年回顾 reflection.app

AI 替你读记录、找模式、给追问。你的统计看板数据恰好是完美原料：升级现有周报——规则模板自动生成数据段（已有），再加"一键把数据段投喂给用户自配的 BYOK Key"生成 AI 点评，数据不出本地，隐私叙事顺理成章。

T·3

游戏化激励Habitica 被评为"游戏化效率黄金标准"（2026 评测定性结论，未引用用户量数字）

习惯/任务绑定 RPG 数值（经验、金币、成长）或养成陪伴。你的徽章墙 + 4000 周人生刻度 + 小花园是现成底座，缺的是可消费的金币与成长线（见建议 #4）。

T·4

时间自动追踪Rize：自动追踪 + AI 教练 rize.io

桌面级自动追踪超出单文件 HTML 的能力边界（Rize/RescueTime 均为常驻 App）。边界内变体：番茄时段归类（工作/学习/生活）+ 待办耗时统计，生成"每日时间去向"——你已有时间去向环形图，可加"自动归类"维度。

T·5

本地优先 + 端到端加密Anytype：本地优先 + P2P + E2EE；Obsidian 同路线

隐私从技术特性升级为一级卖点。你已是极致形态（单文件 + 本地存储），缺的只是把隐性优势显性化：云同步支持"上传前本地加密"，介绍文案把"数据完全在你手里"写进第一屏。

05

优化建议 Top 7

按「价值 ÷ 实现成本」排序，全部遵守两条底线：不破坏单文件架构、不引入云依赖。每条标注原型来源与成本量级。

1

年度报告页「我的 2026」原型：Spotify Wrapped

复用统计看板全部数据，做成翻页全屏动效页：专注总时长、打卡最长连续、最忙的一天、心情曲线、年度账单 TOP 分类、点亮的人生格子数……12 月 31 日自动解锁，支持导出长图。季度小版本可复用同一引擎。

为什么值 仪式感与分享欲是效率工具最稀缺的东西；纯前端零依赖。成本 ★★☆
2

递归复盘链：周报 → 月报 → 季报原型：LifeOS for Obsidian

月报不重新生成，而是自动汇总四周周报的数据段 + 逐条引用各周手写总结；季报同理。写周报时自动带出上月同期对比。周报引擎升级一次，三级复盘全通。

为什么值 你已有周报，这是最小改动换最大结构升级的一步。成本 ★☆☆
3

一句话录入层原型：滴答清单 / 一木记账

Ctrl+K 的智能捕捉升级：日期词解析已有（明天/周三），扩展到「下午3点」时刻解析；新增记账分支——检测到金额即走记账（「午饭32」→ 金额 32 + 关键词映射分类），复用语音笔记的识别结果即得语音记账。待办与记账共用一套解析器。

为什么值 录入摩擦每降一格，日活留存涨一截；一套解析器吃两个模块。成本 ★★☆
4

专注金币经济原型：Forest（金币机制据 2018 年资料）

番茄与打卡产出"露水/金币"，可在商店兑换：动态壁纸主题、白噪场景、小花园植物品种、书架皮肤、涂鸦板笔刷。放弃的番茄仍留枯苗（已有），周报新增"枯萎率"。徽章是收集欲，经济是参与感，两者不互斥。

为什么值 把"坚持"变成"攒了还没花"，沉没成本替你留住用户。成本 ★★☆
5

心情晴雨表原型：Moo 日记

在既有心情月历色点之上补三种视图：ECharts 情绪温度曲线（周/月）、情绪占比环图、心情 × 活动标签交叉（"做什么时心情最好"）。全部接进周报。

为什么值 数据早就在，只差视图；情绪可视化是日记类产品最强的周留存钩子。成本 ★☆☆
6

番茄场景预设 + 自定义 API 卡片原型：潮汐 / Homarr

前者：白噪组合 + 时长 + 主题保存为一键场景（"深夜图书馆""雨天咖啡馆"）。后者：自定义卡片开放"填 endpoint 渲染 JSON"的通用卡，让用户自己接任意数据源，无需你逐个实现集成。

为什么值 场景化提升专注页仪式感；API 卡片把"功能扩展"外包给用户。成本 ★★☆
7

隐私显性化 + 标签树反链原型：Anytype / flomo

前者：云同步加"上传前本地加密"选项，首页文案把"数据完全在你手里"提为一级卖点。后者：日志与笔记加标签树 + 反向链接，配合"那年今日"卡（已有）形成回顾网络。

为什么值 一个是零成本的定位资产，一个是低成本的知识复利。成本 ★☆☆
06

定位建议与边界

调研下来，你的项目不需要改定位，需要把三张牌摊开说：

极致本地

单文件 + 双击即开 + 数据 100% 本机——比 Obsidian / Anytype 更彻底。把"没有账号、没有服务器、没有追踪"写进第一屏，这是海外 local-first 趋势验证过的一级卖点。

全养护心

29 个模块共享一套"晨雾奶油"视觉语言——竞品里没有同时覆盖效率 + 记录 + 情绪 + 娱乐的单一产品。温柔感是护城河，别让新功能破坏呼吸感。

回顾即奖励

统计看板 + 徽章 + 人生刻度已具雏形；加上年度报告与复盘链后，"回顾"从功能升格为产品的情感核心——每天打开它，不只是记录，是被自己看见。
